# 5회 정답 — CLAUDE.md 예시

> 시작 브랜치는 `start/ledger-ep05`입니다. `start/ledger-ep07` 브랜치의 `CLAUDE.md`가 이 정답의 실제 파일입니다.

## 이 저장소에 이미 관철돼 있으나 어디에도 적혀 있지 않은 규칙 3종

1. **화면에 보이는 모든 금액은 `formatWon()`을 거친다.** 숫자를 그대로 찍은 곳이 한 군데도 없다.
2. **주석은 한국어로 쓴다.** 이름은 영어, 설명은 한국어다.
3. **새 통계 함수는 `src/stats.js`에 둔다.** 통계 로직이 다른 파일에 흩어져 있지 않다.

## 정답 CLAUDE.md

`start/ledger-ep07` 브랜치의 실습 폴더(`practices/01-household-ledger/`) 맨 위에 있는 `CLAUDE.md`를 그대로 보세요.

```
git switch start/ledger-ep07
cat CLAUDE.md
```

## "규칙을 어긴 코드가 안 나왔는데요?"

**그것도 정상입니다.** Claude Code는 주변 코드를 읽고 스스로 관습을 맞추기도 합니다.
이 실습의 목적은 "위반을 목격하는 것"이 아니라 **전·후를 비교해 적어 보는 것**입니다.

규칙이 지켜져서 나왔다면 이렇게 물어보세요 — *"왜 `formatWon()`을 썼어?"*
답을 들으면 도구가 무엇을 근거로 판단하는지가 보입니다. 그게 CLAUDE.md를 쓰는 이유이기도 합니다.

## 곁다리 — `src/app.js`의 검색 결함

이 브랜치에는 빨강이 1개 남아 있습니다(**"검색어 앞뒤 공백을 무시하고 찾는다"**).
`searchItems()`의 `var word = keyword;` 를 `var word = keyword.trim();` 으로 고치면 됩니다.
5회 본 실습은 아니지만, 새 규칙을 세운 뒤 곧바로 적용해 볼 연습감으로 쓰세요.
