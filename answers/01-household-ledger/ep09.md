# 9회 정답 — MCP 서버 연결

> 시작 브랜치는 `start/ep09`입니다. **이 회차만 Node.js 18 이상이 필요합니다.**

## `.mcp.json`

저장소 맨 위 폴더에 만듭니다.

```json
{
  "mcpServers": {
    "moneybook": {
      "command": "node",
      "args": ["mcp/moneybook-server.js"]
    }
  }
}
```

## 확인 순서

1. 파일을 만든 뒤 **세션을 새로 시작**합니다 (`claude`).
2. **이 프로젝트의 MCP 서버를 신뢰하겠냐는 승인 질문이 뜹니다.** 승인해야 붙습니다.
   (실측 확인: 승인 전에는 `claude mcp list`에 `⏸ Pending approval`로 나옵니다.)
3. `/mcp` 를 입력합니다 → 목록에 **`moneybook`** 이 **connected** 로 보이면 성공입니다.

## 물어볼 질문과 정답 숫자

> **"2025년 12월 식비 합계 알려 줘"**

답에 **`47,900원`** 이 나오면 도구 호출이 실제로 일어난 것입니다.

다른 확인용 숫자:

| 질문 | 정답 |
|---|---|
| 전 기간 식비 합계 | 200,600원 |
| 전 기간 전체 합계 | 3,290,334원 |
| 2025-12 전체 합계 | 931,400원 |

## "정말 도구를 쓴 게 맞나?" 확인하기

`.mcp.json`의 파일 경로를 일부러 틀리게 고치고 세션을 새로 시작한 뒤 같은 질문을 해 보세요.
**답하지 못하거나 연결 실패가 표시되면**, 앞의 답은 도구에서 온 것이 맞습니다.

## 이 서버가 하는 일

`mcp/moneybook-server.js`는 도구 3개를 열어 줍니다 — `total_by_category`, `total_by_month`, `list_expenses`.
바깥에서 가져온 라이브러리 없이 Node 표준 기능만으로 만들었습니다. `npm install` 은 필요 없습니다.
