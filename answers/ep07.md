# 7회 정답 — 슬래시 명령어와 훅

> 시작 브랜치는 `start/ep07`입니다.

## 슬래시 명령어 — "테스트 돌리고 실패 항목만 요약"

저장소 안에 `.claude/commands/test.md` 파일을 만듭니다. **파일 이름이 명령 이름이 됩니다** (`/test`).

```markdown
---
description: 테스트를 돌리고 실패한 항목만 요약한다
---

`node tests/run.js` 를 실행하고, 결과에서 다음만 알려 줘.

1. 맨 아래 요약 줄 (`N개 중 M개 통과 / K개 실패`)
2. 실패한 항목의 이름과 기대값·실제값
3. 통과한 항목은 나열하지 말 것
```

확인: 세션에서 `/` 를 입력하면 목록에 `test` 가 보입니다. 실행하면 `19개 중 …` 형태가 나옵니다.

## 훅 — 파일을 고치면 자동으로 테스트

`.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "node tests/run.js" }
        ]
      }
    ]
  }
}
```

설정 후 세션을 새로 시작하고 아무 파일이나 한 줄 고치게 하면, **시키지 않았는데** 테스트 결과가 나옵니다.

자세한 설명은 실습 브랜치의 `docs/hook-example.md`에 있습니다.

## 주의

- 훅은 Node.js가 있어야 돕니다. 없으면 슬래시 명령어만 하고 훅은 건너뛰세요.
- 훅에 무거운 명령을 걸면 **모든 편집이 그만큼 느려집니다.** 가벼운 것부터 걸어 보세요.
