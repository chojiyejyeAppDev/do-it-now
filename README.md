# 정답·해설 브랜치

**먼저 스스로 해 보세요.** 여기에는 회차별 정답과 해설이 들어 있습니다.

이 브랜치에는 앱 코드가 없습니다. 실습 코드는 `main`과 `start/*` 브랜치에 있습니다.
정답을 실습 브랜치에 두지 않은 이유는, 저장소 안에 정답 파일이 있으면 Claude Code가
탐색 중 그 파일을 읽고 곧바로 답을 적용해 버려 실습이 성립하지 않기 때문입니다.
