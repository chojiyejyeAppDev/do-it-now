# 간단 가계부 — Claude Code 교육 시리즈 실습 저장소

> 📍 지금 보고 계신 브랜치는 **`start/ep11`(11회 시작 상태)** 입니다.
> `src/csv.js`의 **가져오기 기능이 아직 만들어져 있지 않습니다** — 그걸 Claude Code에게 맡기는 것이
> 11회 실습입니다. `.claude/agents/`는 비어 있습니다. 처음부터 하려면 `git switch main` 하세요.

쓴 돈을 적으면 합계와 분류별 통계를 보여 주는 작은 웹 앱입니다.
**설치할 프로그램은 없습니다.** 파일을 내려받아 더블클릭하면 바로 열립니다.

> ⚠️ **이 저장소에는 실습을 위해 일부러 심어 둔 결함이 있습니다.**
> 실제로 가계부를 쓰기 위한 프로그램이 아닙니다. 결함이 어디에 있는지는 밝히지 않습니다 —
> 그걸 찾아 고치는 것이 실습이기 때문입니다.
>
> ⚠️ **Pull Request 목록은 직접 해 보시기 전에 열지 마십시오.**
> 다른 학습자가 고친 코드가 그대로 보입니다. 답을 미리 보게 됩니다.
> (막혔을 때 볼 정답은 `answers` 브랜치에 따로 있습니다 — 보실지는 학습자가 정하시면 됩니다.)

## 3분 시작하기

**1. 저장소를 내려받습니다**

```
git clone https://github.com/chojiyejyeAppDev/do-it-now.git
cd do-it-now
```

→ *이렇게 보이면 성공:* `do-it-now`라는 폴더가 생기고, 그 안에 `index.html` 파일이 보입니다.

**2. 앱을 엽니다** — 폴더 안의 `index.html`을 **더블클릭**합니다.

→ *이렇게 보이면 성공:* 브라우저가 열리고 지출 목록 표에 **60건**이 보입니다.

**3. 테스트를 엽니다** — 같은 폴더의 `tests.html`을 **더블클릭**합니다.

→ *이렇게 보이면 성공:* 맨 위에 큰 글씨로 **`19개 중 18개 통과 / 1개 실패`** 가 보이고,
빨간 ✗ 가 3개 있습니다. **이게 정상입니다** — 고치라고 심어 둔 결함이니까요.

**4. Claude Code를 켭니다** — 터미널에서 저장소 폴더에 들어간 뒤 `claude` 를 실행합니다.

→ *이렇게 보이면 성공:* 세션 맨 위에 `do-it-now` 폴더 경로가 보입니다.

## 회차 ↔ 브랜치 대응표

각 회차는 시작 상태가 다릅니다. 실습 전에 아래 명령 한 줄을 복사해 붙여넣으세요.
(비개발자라면 Claude Code에게 **"start/ep05 브랜치로 옮겨 줘"** 라고 말해도 됩니다.)

| 회차 | 명령 | 시작 상태 |
|---|---|---|
| 1회 재실습 | `git switch -c my-ep01 origin/main` | 기본 상태 |
| **3회** | `git switch -c my-ep03 origin/main` | 결함 3건, 테스트 **3개 실패** |
| 5회 | `git switch -c my-ep05 origin/start/ep05` | 3회 결함 수정됨, `CLAUDE.md` 없음 |
| 7회 | `git switch -c my-ep07 origin/start/ep07` | `CLAUDE.md` 있음, `.claude/` 비어 있음 |
| 9회 | `git switch -c my-ep09 origin/start/ep09` | `mcp/` 서버 포함, `.mcp.json` 없음 |
| 11회 | `git switch -c my-ep11 origin/start/ep11` | CSV 가져오기 미구현 |

2·4·6·8·10·12회(최신편)는 이 저장소가 필요하지 않습니다.
자세한 대응표는 [`docs/START-HERE.md`](docs/START-HERE.md)에 있습니다.

## 대표님·학습자용 안내 — fork 할까요, clone 할까요?

| 상황 | 방법 |
|---|---|
| 실습 결과를 내 GitHub에 남기고 싶다 | 이 저장소를 **fork** 한 뒤 자기 fork를 clone |
| 그냥 실습만 해 보면 된다 | **clone만 해도** 전 회차 실습이 다 됩니다 |
| 이 저장소의 소유자(대표님)다 | 자기 저장소는 fork할 수 없습니다. `git clone` 후 **자기 브랜치**에서 작업하세요: `git switch -c daepyo-ep03` |

원본 저장소는 **읽기 전용으로 소비**됩니다. 여러 명이 동시에 써도 서로 영향을 주지 않습니다.

## 잘 안 될 때

| 증상 | 흔한 원인 | 이렇게 하세요 | 이러면 정상 |
|---|---|---|---|
| `index.html`을 눌렀는데 글자만 잔뜩 보인다 | 브라우저가 아니라 편집기로 열렸다 | 파일 우클릭 → "다음으로 열기" → 브라우저 선택 | 지출 목록 표가 보인다 |
| 화면은 떴는데 목록이 비어 있다 | 저장된 기록이 지워졌다 | 화면 아래 **샘플 데이터 넣기** 버튼을 누른다 | 목록에 60건이 보인다 |
| 새로고침하면 입력한 내용이 사라진다 | 브라우저 저장이 막혀 메모리 모드로 도는 중 | 화면 위 노란 띠를 확인. 실습에는 지장 없음 | 노란 띠가 보이면 "알려진 상태" |
| `tests.html`이 전부 빨갛다 | 수정이 과했거나 브랜치를 잘못 잡았다 | `git switch main` → `git checkout -- .` (Claude Code에 "저장소를 원래 상태로 되돌려 줘"라고 해도 됩니다) | 다시 열면 **2개 실패**로 돌아온다 |
| `claude`가 파일을 못 찾는다 | 저장소 폴더 밖에서 세션을 시작했다 | `cd do-it-now` 후 다시 `claude` | 세션 맨 위에 저장소 폴더 경로가 보인다 |
| (9회) `/mcp`에 목록이 안 뜬다 | Node.js 미설치 또는 설정 파일 위치 오류 | `node --version` 확인 → 없으면 설치. 설정 파일은 저장소 맨 위 폴더에 둔다 | `moneybook`이 connected로 표시 |

## 터미널로 테스트하기 (선택)

Node.js 18 이상이 설치돼 있다면 터미널에서도 같은 테스트를 돌릴 수 있습니다.

```
node tests/run.js
```

브라우저와 터미널이 **같은 코드를 검사**합니다. 결과가 다르면 그건 버그입니다 — 알려 주세요.

## 정답은 어디에 있나요

정답과 해설은 `answers` 브랜치에 있습니다.

```
git switch answers
```

**먼저 스스로 해 보세요.** 정답을 실습 브랜치에 두지 않은 이유는, 저장소 안에 정답이 있으면
Claude Code가 그 파일을 읽고 곧바로 답을 적용해 버려서 실습이 성립하지 않기 때문입니다.
