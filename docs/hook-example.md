# 훅 설정 예시 (7회용 — 설명 문서입니다)

> 이 문서를 저장소에 두는 것만으로는 **아무 일도 일어나지 않습니다.**
> 7회 실습에서 이 내용을 직접 설정 파일로 옮기는 것이 과제입니다.

## 훅이란

Claude Code가 **어떤 일을 한 직후에** 내가 정한 명령을 자동으로 실행하게 하는 장치입니다.
"파일을 고쳤으면 테스트를 돌려라" 같은 규칙을 사람이 매번 말하지 않아도 되게 만듭니다.

## 예시 — 파일을 수정할 때마다 테스트를 돌린다

`.claude/settings.json` 에 아래 모양으로 넣습니다. **이 저장소에는 일부러 넣어 두지 않았습니다.**

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "node tests/run.js" }
        ]
      }
    ]
  }
}
```

## 확인 방법

1. 위 설정을 넣고 Claude Code 세션을 새로 시작합니다.
2. 아무 파일이나 한 줄 고치도록 시킵니다.
3. **시키지 않았는데** 테스트 결과(`17개 중 …`)가 화면에 나타나면 훅이 걸린 것입니다.

## 주의

- `node tests/run.js` 는 Node.js가 설치돼 있어야 돕니다. 없다면 훅 대신 슬래시 명령어 실습만 하세요.
- 훅은 **내가 만든 자동 실행**입니다. 무거운 명령을 걸면 작업이 매번 느려집니다.
